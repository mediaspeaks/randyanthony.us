# randyanthony.us

**RANDI | Randy Anthony Network And Digital Interface**

Personal website and working archive for Randy Anthony, focused on operational reliability, operational visibility, broadcast and streaming systems, publications, radio, and related projects.

- **Operational Visibility Series**: `/series/`
- **Advisory Services**: `/services.html`
- **Books & Publications**: `/book/`
- **Radio / The Sound of the Strand**: `/radio/`
- **2026 Projects**: `/2026/`

## Purpose

The site brings together Randy Anthony’s professional work, publications, operational research, media projects, and selected personal projects in one maintained web presence.

The Operational Visibility Series examines reliability, decision-making, hidden dependencies, operational drift, and the ways small decisions can create larger operational consequences.

## Hosting & Deployment

The site is maintained in this GitHub repository and published through GitHub Pages. DNS is managed through Cloudflare.

Live site: https://randyanthony.us/

## Repository Notes

This repository contains both active website files and selected historical or archival versions retained for reference. Older, non-live, test, and superseded files are intentionally preserved when they have archival value.

Not every file in the repository is intended to be indexed or linked from the live site. The sitemap is deliberately selective and represents the site’s intended public indexing surface.
